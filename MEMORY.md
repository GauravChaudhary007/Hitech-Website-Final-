## Homepage build notes (2026-09-22)

- Built the full homepage: cinematic pinned hero (GSAP ScrollTrigger + Three.js network with scroll-driven lighting) leading into a scroll-synced product slideshow, client logos, product journey, why-us, testimonials, and contact CTA.
- **Real product screenshots exist on the old site** under `/images/app-shot/` for exactly 3 products: Swastik (`swastik-accounting-shot2/3.png`), Swastik POS (`swastik-pos-shot-2..5.jpg`), Swastik Restaurant ERP (`swastik-restaurant-erp-1..3.jpg`) — all real Windows desktop app screenshots, self-hosted into `public/products/` (one per product used). The other 3 flagship products (myswastikonline, HiTech ERP, Pharmasoft) only have a shared, generic, low-res placeholder image on the old site (`app-shot-1..7.jpg`) reused across all three — **not real distinct screenshots**, so the rebuild uses honest illustrated abstract-dashboard panels for those instead of pretending they're authentic (see `ProductFrame.tsx`/`IllustratedPanel`).
- The hero's slideshow and the `ProductJourney` section below it share the same `ProductFrame` component — hero autoplay is tied to the pinned-hero scroll progress (not a timer), and `ProductJourney` syncs the same frame to which product's text block is centered in view (GSAP ScrollTrigger, desktop only; mobile shows each product's frame inline instead of sticky).

## Stack & design decisions already made

- **Framework:** Next.js 16 (App Router, TypeScript, `src/` dir, Turbopack), Tailwind CSS v4 — chosen for SSR/SEO given the site's current poor search/press visibility.
- **Animation:** Framer Motion (component/UI-level), GSAP + ScrollTrigger (scroll sequences), Three.js via `@react-three/fiber`/`@react-three/drei` (single hero-level 3D moment only, lazy-loaded) — full rationale in `DESIGN.md`.
- **Design direction:** "Trust & Authority + Conversion" pattern, "Accessible & Ethical" style, navy/slate/blue-accent palette, Lexend + Source Sans 3 typography — see `DESIGN.md` for full tokens and open decisions still needing HiTech sign-off.
- Explicitly **not** using: any Claude "skill" named framer-motion/three.js/gsap/design-dna/genjutsu — none of those exist as installable skills in this environment; "Design DNA" and "Genjutsu" were dropped per user decision on 2026-09-22 (Genjutsu turned out to be an unrelated video-motion-transfer feature in a different tool, not applicable to web dev).
